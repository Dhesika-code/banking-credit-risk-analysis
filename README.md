# Banking Credit Risk and Fraud Analysis

## About
This project analyzes credit risk, loan applications, and fraudulent transactions using Python, SQL, and Power BI.

## Tools
- Python and Jupyter Notebook
- MySQL
- Power BI

## Project folders
- `Python/` - Notebooks and Python files
- `SQL/` - SQL queries
- `PowerBI/` - Power BI dashboard file
- `Images/` - Dashboard screenshots and charts
- `Dataset/` - Project datasets

## Dashboard
The Power BI report contains pages for Executive Summary, Fraud Analysis, Credit Risk, Customer Analysis, and Prediction Dashboard.

## Note
This is a learning project. Model results are for educational use.
